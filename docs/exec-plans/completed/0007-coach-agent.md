# 0007 — Coach Agent

## Context

Book retrieval (0005/0006) could search imported books, but nothing
coached with them. `AGENTS.md` listed the coach agent/chat as not built.
The rider wanted a Coach section in the web UI, available once Garmin is
connected, where they can ask about their activities and how to improve.

The coach should:
- learn about the rider from their rides and from what they say,
- recommend training grounded in the ingested books,
- refuse anything that isn't about bikes and training.

Decisions made with the rider:
- Learning is memory notes plus ride data.
- Threads persist, and replies stream.
- Scope is cycling plus adjacent topics (nutrition, recovery, gear, fit and injury prevention in a cycling context).

Done means:
- the dashboard opens a streaming chat that answers from sensor-gated ride data and cited book passages,
- off-topic and role-change prompts are refused,
- memory notes persist and can be deleted,
- every paid call is recorded and a monthly budget is enforced,
- REST and MCP agree on the shared data.

## Design

The behavior is specified in `product-specs/coach-chat.md`. Code layout:

- **LLM layer**
  - `llm/client.py` adds `chat_stream` (text deltas, then `ChatDone` with tool calls and usage) and `chat_json` (strict JSON schema).
  - `llm/usage.py` holds `record_usage`, `month_to_date_cost` and `ensure_within_budget`. RAG now uses the shared recorder.
- **`coach/`** in core:
  - `guardrail.py`: a fail-closed scope classifier and the fixed refusal.
  - `prompts.py`: the static system prompt, kept static so it can be prompt-cached.
  - `tools.py`: seven function tools, each calling into existing core services.
  - `memory.py`: note CRUD with caps.
  - `service.py`: conversation CRUD, `check_turn` and the `run_turn` agent loop. The loop runs at most 4 tool rounds, and the last round gets no tools so the model has to answer.
- **Activities**: `get_training_summary` gives weekly volume, with HR and power averaged only over verified rides.
- **Schema**: `coach_conversation`, `coach_message` and `coach_memory_note` (migration `c2dbf4b4e115`).
- **Server**: thin REST routes, including the SSE `StreamingResponse`, and four MCP tools.
- **Web**:
  - `pages/Coach.tsx` has the conversation list, thread with streaming draft, tool-status line, source chips, memory panel and suggestions.
  - `components/CoachText.tsx` is a safe Markdown-subset renderer.
  - `api.streamCoachMessage` reads the SSE stream.
  - The dashboard's "Ask your coach" button is gated on a connected provider.

## Verification

- `tests/test_coach.py` has 16 tests using a scripted `FakeLLM`. They cover:
  - Guardrail:
    - off-topic messages are refused and never reach the coach model,
    - the classifier fails closed,
    - follow-ups see the previous reply.
  - Agent loop:
    - the tool loop reads core data, saves memory and cites books,
    - memory notes are injected into the prompt,
    - the last round withholds tools,
    - usage rows are recorded for every paid call.
  - Validation and budget:
    - the budget guard blocks turns in core and returns 402 over REST,
    - input validation and missing-key handling,
    - memory caps and dedupe.
  - Sensor honesty:
    - the weekly summary never averages unverified HR or power,
    - `get_ride` hides unverified lap power.
  - Surfaces:
    - SSE over REST streams the reply and persists it,
    - MCP and REST agree on memory and the training summary.
- `make check` is green: ruff, format, `tsc`, and all pytest tests. The web production build also passes.
- A live end-to-end run used a copy of the real DB (polling off) on alternate ports, through the Vite proxy:
  - **Streaming:** the reply arrives incrementally (158 SSE events).
  - **Memory:** "remember my knee…" was saved as a note.
  - **Book grounding:** a follow-up searched the books and cited *The Cyclist's Training Bible* and *Mastering Mountain Bike Skills*.
  - **Refused:** Python script, capital of France, "ignore instructions" jailbreak, fake-developer prompt leak, stock picking.
  - **Answered:** "hi coach!", pre-fondo nutrition, chain skipping on the 11t cog, "thanks, why that?".
  - **Cost:** about $0.0015 across 3 chat calls in the first turn.
- **Not verified:** a visual browser check of `Coach.tsx`. The Chrome extension was not connected during this session.
